gophkeeper - сервис реализующий cli, для передачи и последующего просмотра приватных данных 

первый шаг - регистрация
    localhost:8080/api/user/register
    
    {
    "login":"test",
    "password":"test"
    }   

второй шаг - авторизация через консоль
    <путь до бинарника(до папки с проектом в данной ситуации)> auth

третий шаг - попытка что-то сохранить
    <путь до бинарника(до папки с проектом в данной ситуации)> save --login "test" --text --text-data "раз два три"
